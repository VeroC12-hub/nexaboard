# Documentation

Grouped by what the document is about, rather than alphabetically, so a
question lands in one folder.

## teaching/

How a learner is taught, and what the tutor is asked for.

- `plan.md` — how the app decides the way a particular learner is taught
- `syllabus.md` — where the curriculum outlines come from and what they claim
- `tutor.md` — the prompts, the tasks and what each one returns
- `asking.md` — what a learner can ask for, and how it changes later lessons
- `games.md` — how a game is composed, and which topics get one

## media/

Everything that is not words.

- `visuals.md` — diagrams, pictures, and which renderer answers
- `video.md` — the lesson video pipeline
- `sound.md` — narration and the voices
- `ananse-counting-3d-film.md` — notes on the counting film

## interface/

What a learner sees, per age.

- `design.md` — the shared design language
- `interfaces.md` — the tiers, and which learner gets which
- `kid-interface.md` — the youngest tier in detail

## platform/

The product around the teaching.

- `product-architecture.md` — how the pieces fit together
- `importing.md` — bringing curriculum documents in
- `NEXABOARD_SCHOOL_PLATFORM.md` — the school-facing platform

## At this level

- `NEXAEDU_OPEN_ISSUES.md` — the open issue list, referenced by number from
  comments throughout the code, so it stays where those references can find it
